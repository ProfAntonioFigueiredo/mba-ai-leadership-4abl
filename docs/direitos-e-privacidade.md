# Direitos, privacidade e publicação

O repositório é privado. Não conceder acesso público ou atribuir licença ampla ao conjunto sem revisar materiais de terceiros, dados e autoria compartilhada.

Não versionar .env real, chaves, tokens, service role, node_modules, builds, ambientes virtuais, Git de terceiros ou arquivos de credenciais. .env.example contém somente exemplos públicos. A senha de demonstração exigida pelo exercício não é uma credencial de produção aprovada.

Materiais de aula e skills recebidas são referências externas. O pacote de skills contém metadados de outro repositório; não copiar esse Git para o portfólio. Preserve atribuições e obtenha os arquivos de fontes autorizadas.

Resumos, notebooks e entregas podem citar pessoas, grupos e identificadores acadêmicos. A visibilidade privada não equivale a uma revisão de privacidade completa. Antes de tornar o portfólio público, preparar uma versão revisada com dados sintéticos e conteúdo cuja redistribuição esteja autorizada.

Não declarar LGPD, licenças de uso, SLA, auditoria imutável ou autorização de publicação como comprovados por esta organização de arquivos.
