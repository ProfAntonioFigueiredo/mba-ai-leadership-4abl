SpeakUp Idiomas — original e evolução SDD

  • Original Vibe Coding: baseline preservada byte a byte, confirmada contra a fonte atual.
  • Evolução SDD: código, testes, specs e evidências.
  • Documentação responsiva: missão, stack, roadmap e comparação.
  • Relatório lado a lado.
  • documentos-origem/: PRD, PSS e requisitos do projeto.

As versões permanecem em diretórios irmãos para executar a comparação. A importação não reescreve a baseline nem encerra fases SDD. A constituição permanece em revisão; produção e todos os requisitos do PRD não estão concluídos.

O helper usa diretório temporário portátil. Os resultados anteriores continuam históricos até a revalidação na nova estrutura. A skill recebida é referência externa no acervo local e não leva seu Git interno para este repositório.
